# azphalt-brush-oil

Brush packages for the "oil" collection, each in its own `brushes/<slug>/` folder (manifest.json + LICENSE + assets/tip.png):

- `brushes/oil-filbert/` — **Filbert** — A soft-edged oval oil brush with subtle bristle streaks. Rotate with angle.
- `brushes/oil-palette-knife/` — **Palette Knife** — A thin, hard-edged blade for dragging and scraping thick paint. Rotate with angle.
- `brushes/oil-fan-blade/` — **Fan Blade** — A fan-shaped brush of radiating tines, for blending and texture streaks.
- `brushes/oil-bristle-drybrush/` — **Bristle Drybrush** — A rough, broken-texture round brush for dry-brush drag effects.

`node build.js` packs every subfolder into its own `.azp`.
